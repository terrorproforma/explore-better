Fast for you. Safe for your AI.

Explore Better is a dual-pane file manager for Windows with a terminal in every tab, a map of your disk space, and copies and moves you can preview, recover and undo.

Its built-in local MCP server lets Codex, Claude, Cursor or VS Code work in the folders you pick. Read-only until you allow writes, and every write is previewed first.

Chapters

    One window for the file work you actually do

    The things that usually send you to a second Explorer window, a separate terminal, or a disk-usage tool are built into the panes you already have open.

    A terminal in every tab

    Each file tab can open its own shell in a drawer below the pane. It starts in that folder, keeps its output when you switch tabs, and can follow you as you browse while it is idle.

    See where the space went

    Disk Map starts scanning when it opens and draws a nested treemap you can drill into, next to folder, file-type and largest-file tables that stay in sync.

    Sizes
    Allocated by default, logical on request, labelled with their source
    Counts
    Hardlinks once; compressed, sparse and cloud files as the drive stores them
    Scans
    Stream results as they run, cancel at any point, reuse warm caches

    Copies and moves you can check first

    Before a byte moves, Explore Better shows what will collide and lets you decide. The work is staged and journalled, so a crash or a pulled cable leaves something it can finish or roll back.

    1. PreviewConflicts listed; rename, overwrite or skip chosen up front
    2. StagePrepared on the destination drive, with backups of anything replaced
    3. CommitEach phase journalled before it runs; pause, cancel or retry
    4. RecoverInterrupted work reconciled at next launch; finished work can be undone

    • Two panes, many tabs

      Source and destination side by side, each with its own tabs, history, filters and view. Vertical, horizontal or single-pane layouts.

    • Huge folders stay quick

      In the 100,000-entry acceptance test the first rows appear in 101.5 ms (median), with only 47 rows ever rendered at once.

    • Search and duplicates

      Filename and content search with size, date and attribute filters, and a duplicate finder with optional SHA‑256 confirmation.

    • Compare and sync

      Left-right folder comparison and explicit sync plans that refuse to apply if the files changed after the preview.

    • Previews, including 3D

      Text, images, PDF, audio and video, plus interactive STL and STEP models rendered locally.

    • A command palette

      Fuzzy search over every command, each labelled with whether it stays in the app, opens File Explorer, or launches something else.

    Let your AI work in your folders, not your whole PC

    Explore Better includes a local MCP server. Your AI client talks to it over stdio on your own machine, with no network listener. Each client gets its own profile: which folders, which tools, read-only or planned writes. Revoke one without touching the others.

    • It sees what you see

      get_context returns your active pane, open tabs, selection and a revision number, so “this folder” means the folder that is open.

    • It gets data, not screen text

      Listings, search, disk analysis, duplicates and comparisons come back as typed, paged JSON from the same indexes and scanner the app uses.

    • It cannot write without a plan

      Every change starts as a preview. Applying it takes a one-use token that expires in 120 seconds and is bound to the exact paths, policy and file signatures.

    Built so mistakes are recoverable

    Whether you or your AI started it, every write goes through the same planner, journal and recovery system. The limits below are part of the design, not settings you have to remember.

    The AI Bridge will not

    • Run shell commands or control your terminals
    • Edit the registry or elevate to administrator
    • Listen on the network; it uses stdio and a same-user named pipe
    • Reach outside a profile’s folders through junctions, device paths or alternate streams
    • Write to Startup folders or AI client configuration files

    What stays on your PC

    Everything. There are no analytics, no account and no cloud file service. The AI Bridge keeps a 30-day local log of which tool ran on which paths, never file contents or tokens. What your AI client does with results is covered by its own terms.

      A current Chromium and Node runtime, with desktop, terminal and update behaviour verified unchanged.

    Questions

    Is Explore Better free?

    Yes. It is free and open source under the MIT license, with source code and releases on GitHub. There is no account, subscription, or paid tier.

    Why does Windows warn me when I run the installer?

    The public preview is not yet Authenticode-signed, so SmartScreen reports an unknown publisher. Download only from the GitHub release, compare the installer’s SHA-256 with the published value, and only then choose More info and Run anyway. Do not turn SmartScreen off.

    Does it replace File Explorer?

    Only if you choose. Explore Better works as a normal app. Making it the default for folder and drive opens is optional; it backs up the exact shell settings it changes, and Restore Previous puts them back. File Explorer stays installed either way.

    Can my AI see all of my files?

    No. The AI Bridge is off until you enable it, and each AI client gets its own profile listing the exact folders and tools it may use. New profiles are read-only; writes need a separate permission and a previewed plan. You can revoke a profile at any time.

    Does anything leave my computer?

    Explore Better has no analytics, account, or cloud file service. The MCP server talks to your AI client locally over stdio. What your AI client does with tool results is covered by that client’s own terms.

    Which AI clients work with it?

    Explore Better has one-click setup for Codex, Claude Desktop, Cursor, and VS Code, and a generic configuration for any MCP host that supports local stdio servers.

    Do I need administrator rights?

    No. The installer is per-user and normal browsing, search, Disk Map, previews, and file operations run as your account. Windows asks for approval only when you open an administrator terminal or touch a protected location.
