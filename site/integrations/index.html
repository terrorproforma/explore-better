The same safety model everywhere

A client name never grants trust. Every connection is constrained by its own profile, authorized roots, tool permissions, limits, and write policy.

  1. Create a profileChoose authorized folders and keep the default read-only mode for initial use.
  2. Install configSelect the client in AI Bridge and use its setup button, or copy the generic stdio snippet.
  3. Test and revokeCall get_context, inspect the audit entry, and revoke the profile whenever access is no longer needed.
